# Bonsai Landing Page Clone

A responsive front-end recreation of Bonsai's marketing/pricing page, built to practice UI interactivity, responsive design, and form validation.

🔗 **Live demo:** https://bonasi.netlify.app

## Features
- Responsive layout (desktop → mobile, tested at 360px width)
- Working Monthly/Yearly pricing toggle with correct price calculations
- Dropdown navigation (Product, Templates) with nested menus
- Mobile hamburger menu with expandable accordions
- Full auth UI flow: Login, Sign Up, Forgot Password
  - Live password strength validation
  - Field validation with error messaging
  - Registered-email check on password reset

## Tech Stack
- HTML5, CSS3, Tailwind,JavaScript (vanilla)

## Known issues / in progress
- OAuth buttons (Google/Facebook) are UI only — not yet connected to a backend auth provider
- Some navigation links are placeholders
- One broken route currently returns a 404 — fix in progress

## Running locally
1. Clone the repo
2. Open `index.html` in your browser (no build step required)
